### 🚀 Ключевые компетенции:
- **Производительность:** Прерывание нецелевых сетевых запросов в памяти до выполнения запросов к БД, сброс кэша (`wp_cache_flush`), оптимизация Nginx.
- **Поисковая оптимизация (SEO):** Точный вайтлистинг официальных поисковых роботов (Yandex, Google, Bing, Mail.ru), сохранение мета-тегов и сниппетов.
- **Безопасность и маршрутизация:** Анализ заголовков, эмуляция кодов ответа шлюзов (Cloudflare 520), сессионная изоляция покупателей.
